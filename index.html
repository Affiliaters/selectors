Affiliaters extension config

Configuration data for the Affiliaters Deal Converter browser extension.

FileRevisionUpdated
v1/selectors.json — —

Online stores change their page markup regularly. This file tells the extension where to find a product's title, price and image on each supported store, so a change can be corrected without asking anyone to update or reinstall anything.

It is data, not code — a list of CSS selectors and text patterns. Nothing served from here is executed. Every value is applied on top of the configuration already inside the extension, so if this file is unreachable the extension simply keeps working as shipped.

Contains no personal data. Not affiliated with any store.
